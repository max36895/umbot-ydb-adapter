# Участие в разработке umbot-ydb-adapter

Спасибо, что хотите помочь! Ниже краткая инструкция.

## Разработка

1. Склонируйте репозиторий.
2. Установите зависимости: `npm install`.
3. Проверьте изменения:
    - `npm run check` — prettier, типы (включая тесты) и ESLint;
    - `npm run build` — сборка в `dist/`;
    - `npm test` — юнит-тесты (SDK YDB в них замокан, сеть не нужна).
4. Если меняли запросы к базе, прогоните `npm run live` на своей базе YDB (см. README, раздел «Проверка на настоящей
   базе»): юнит-тесты проверяют текст запросов, но не то, как его выполнит YDB.

## Правила

- Комментарии и JSDoc — на русском: что делает код и почему он так устроен.
- Без `any`: `unknown` с сужением типа или строгие интерфейсы.
- Значения в YQL — только параметрами; имена таблиц и колонок — через `quoteTable` / `quoteColumn`.
- Каждый новый оператор, тип колонки или ветка ошибки покрывается тестом.
- Запись в `CHANGELOG.md` — в раздел будущей версии.

## Pull Requests

- Ветка от `main` с именем `feature/...` или `fix/...`.
- В описании — что изменилось и как проверено (юнит-тесты, `npm run live`).
- CI должен быть зелёным.

## Issues

- Перед созданием проверьте, нет ли дубликата.
- Приложите версии Node.js, umbot и адаптера, режим базы (Serverless / Dedicated / локальная) и текст ошибки из лога
  без токенов и строк подключения с секретами.

## Лицензия

Принимая участие, вы соглашаетесь, что ваш код будет распространяться под лицензией MIT.
